Instalacion rapida

        

          Copia estos comandos en Kali Linux o en una distribucion basada en Debian. El instalador crea el entorno virtual, instala dependencias y prepara las herramientas del laboratorio.
        

      

      
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip libimage-exiftool-perl
git clone https://github.com/codecatcoding/OSINTLAB.git ~/OSINTLAB
cd ~/OSINTLAB
bash Scripts/install_kali.sh
./venv/bin/python run.py
